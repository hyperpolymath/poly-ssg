Interactive comparison of SSG engines (Casket, Hackenbush, Bunsenite, Cobalt) built with ReScript, Deno, and formally verified components from proven.

== Historical architecture claims

* *ReScript* - Type-safe frontend compilation
* *Deno* - Modern runtime (no Node.js per RSR)
* *proven* - Formally verified string operations
* *TEA* - The Elm Architecture for state management

=== Historical verification claims

This site uses *ProvenSafeString* from the proven library for safe config generation, ensuring:

* No string overflow or underflow
* Memory-safe concatenation
* Proven correctness of output format

== Historical development instructions

=== Build

[source,bash]
----
# Build ReScript to JavaScript
deno task build

# Watch mode
deno task watch

# Clean artifacts
deno task clean
----

=== Local Server

[source,bash]
----
deno run -A jsr:@std/http/file-server .
# or
python3 -m http.server 8000
----

=== Historical GitHub Pages deployment instructions (unqualified)

Primary Pages deploy now uses `ddraig-ssg` (Idris 2) via:

* `.github/workflows/deploy-ddraig.yml` (auto on `main`)
* Custom domain: `axiom.metadatasticaian.art` (via `_site/CNAME`)

Casket deploy remains available as a manual fallback workflow:
`.github/workflows/deploy-casket.yml`.

[source,bash]
----
cd engines/ddraig-ssg
idris2 Ddraig.idr -o ddraig
./build/exec/ddraig build ../../content ../../_site
echo "axiom.metadatasticaian.art" > ../../_site/CNAME
----
