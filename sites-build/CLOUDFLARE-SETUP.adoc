==== 8. Workers (Optional for http-capability-gateway)

*Use Case*: Implement HTTP 430 (Consent Required)

[source,javascript]
----
// HTTP 430 Worker (consent-aware-http)
export default {
  async fetch(request, env) {
    const url = new URL(request.url);

    // Check for consent header
    const consent = request.headers.get('X-Consent-Token');

    if (!consent && url.pathname !== '/.well-known/aibdp.json') {
      // Return HTTP 430 Consent Required
      return new Response('Consent required. See /.well-known/aibdp.json', {
        status: 430,
        headers: {
          'Content-Type': 'text/plain',
          'X-Consent-Required': '/.well-known/aibdp.json'
        }
      });
    }

    // Proceed to origin
    return fetch(request);
  }
}
----

*Deployment*: One worker per domain (or shared across domains)
